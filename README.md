# Ricardo Paz

Desarrollador full-stack con más de cinco años de experiencia, en Santiago de Compostela. Trabajo sobre todo con **C#, .NET y MySQL**: servicios de Windows que automatizan procesos entre bases de datos y sistemas externos, integraciones con APIs y herramientas para desplegarlos y vigilarlos en producción. Fuera del trabajo construyo herramientas de análisis de datos y de IA local, desarrolladas con ayuda de agentes como Claude y Codex.

## Qué hago

- **Servicios de Windows en C#/.NET** sobre MySQL: inserción y sincronización de estados por lotes, optimización de consultas y del uso de conexiones, y gestión segura de credenciales.
- **Integraciones** con servicios SOAP y APIs REST.
- **Herramientas internas**: un gestor de servicios con monitorización de bases de datos y relanzamiento automático, y un desplegador de versiones.
- **Análisis de datos** con Python (pandas, Streamlit, matplotlib) y herramientas web sin dependencias.

## Tecnologías

C# · .NET Framework 4.8 · .NET 8/10 · WPF · Windows Services · MySQL · PowerShell · Python · Streamlit · JavaScript · HTML/CSS · Lua · Android (Java) · Ollama · Git
